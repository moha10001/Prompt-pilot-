# Seller Prompt Builder

Zero-dependency browser tool for digital-product sellers.

Build structured AI prompts for research, listings, SEO, positioning, social, email and launch — without an API key, database or subscription.

## Workflows (16)

**Core**
1. Product idea research
2. Listing title + description
3. SEO keywords and tags
4. Product positioning
5. Social media launch
6. Email promotion
7. Competitor analysis
8. Product launch plan

**Specialized**
9. Etsy SEO title + tags optimizer
10. Printable / planner listing copy
11. Canva template product listing
12. Pinterest pin copy + SEO
13. FAQ + buyer objection handler
14. Bundle & upsell offer copy
15. Seasonal / holiday product angle
16. Post-purchase & review request emails

## Features
- Marketplace selector: Etsy · Shopify · Gumroad · General
- Copy button + TXT download
- Fully offline (single HTML file)
- No external libraries

## How to use
1. Open `index.html` in any modern browser
2. Enter product, customer, goal and extra details
3. Choose a task / workflow
4. Click **Build Prompt** → Copy or Download
5. Paste into ChatGPT, Claude, Gemini or any AI tool

## GitHub Pages
Upload `index.html` to a repository root (or this folder), enable GitHub Pages, publish from the main branch.
