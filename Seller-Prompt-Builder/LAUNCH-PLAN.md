# LAUNCH PLAN — Seller Prompt Builder

## Goal
Validate demand fast with a low-price digital product, collect real buyer feedback, then expand the highest-value workflows.

---

## Phase 0 — Prep (Day 1)

### Product readiness
- [x] Core tool (`index.html`) with specialized workflows
- [ ] 4–6 clean screenshots (desktop)
- [ ] Optional 20–30s screen recording / GIF
- [ ] Cover / thumbnail image
- [ ] Final price decision (recommended: $5.99 or $6.99)

### Sales assets
- [ ] Gumroad (or Etsy) product page using `PRODUCT-LISTING.md` copy
- [ ] Short demo text: “Fill product → choose task → get structured prompt in seconds”
- [ ] 1 before/after example (weak prompt vs tool output)

### Technical
- [ ] Optional: publish a free demo version on GitHub Pages (limited workflows or watermark)
- [ ] Confirm download file = clean `index.html` + short README for buyers

---

## Phase 1 — Soft Launch (Days 1–7)

### Where to list
1. **Gumroad** (primary — fast setup, low friction)
2. **Etsy** (secondary — search traffic for “Etsy seller tools / AI prompts”)
3. Optional: own simple landing page later

### Price
- Launch at **$5.99** or **$6.99**
- Mark as “Introductory price” in the description

### Distribution (low-cost)
- Post in 2–3 relevant Facebook / Reddit communities (no spam — show the problem + short demo)
- Share a free sample prompt generated by the tool (screenshot)
- Short LinkedIn / X post: “Built a zero-API prompt builder for Etsy & digital product sellers”
- If you have an email list or audience → one short announcement

### What to measure
- Product page views
- Conversion rate (views → purchases)
- Refund / support messages
- Which workflow buyers mention most

---

## Phase 2 — Feedback & Quick Wins (Days 7–21)

### Collect
- Ask every buyer 1 question: “Which workflow was most useful?”
- Note any confusion in the UI or missing fields

### Improve first
1. Highest-used workflow (clarity + output quality)
2. Add 1–2 missing specialized flows if buyers ask
3. Better onboarding line inside the tool (one sentence at top)

### Content
- Publish 1 short case-style post: “How I generate Etsy listing prompts in 60 seconds”
- Update listing with real buyer language if available

---

## Phase 3 — Expansion (Weeks 4–8)

Only after you have sales signal:

1. Raise price to **$9–$12** if conversion stays healthy
2. Add **Etsy-specific** and **Shopify-specific** deeper packs (or separate listings)
3. Add Arabic UI version if Arabic demand appears
4. Bundle option with Prompt Pilot main tool (higher ticket)
5. Optional: simple video walkthrough for the product page

### Product roadmap priority
1. Improve top 3 workflows by usage
2. Add 5–10 more specialized workflows (printables, seasonal, bundles, Pinterest)
3. Light UX polish (examples, sample fill button)
4. Marketplace-specific versions only if demand is clear

---

## Phase 4 — Scale (After product-market fit signal)

Signals that you’re ready:
- Consistent weekly sales without heavy promotion
- Low refund rate
- Buyers asking for “more of this”

Then consider:
- Paid ads only on proven angles (Etsy SEO prompts, digital product listing AI)
- Affiliate / creator partners in digital product niches
- Higher-tier “Pro workflows” pack

---

## Weekly Checklist (first 4 weeks)

| Week | Focus |
|------|--------|
| 1 | List product + 5–10 organic shares + track views |
| 2 | First feedback + fix friction + 1 content post |
| 3 | Improve top workflow + add 1 specialized flow if needed |
| 4 | Review price, conversion, next expansion decision |

---

## Do Not Do Early
- Heavy paid ads before organic validation
- Building a full SaaS / accounts system
- Adding 50 workflows before buyers use the first 16
- Over-polishing design before sales proof

---

## Success Criteria (30 days)
- At least some real purchases (even small volume is signal)
- Clear answer to: “Which 2–3 workflows matter most?”
- Enough feedback to justify price increase or specialization

---

## One-sentence strategy
Ship a cheap, clear tool → sell it where digital sellers already look → learn which workflows they actually use → double down on those.
